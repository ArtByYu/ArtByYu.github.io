# art.byyu — Wedding Fingerprint Trees

A free static website designed for GitHub Pages.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` and `style.css` to the repository.
3. In GitHub: **Settings → Pages → Deploy from branch → main / root**.
4. Replace `YOUR_EMAIL_HERE` in `index.html` with your real email address.
5. Your site will be available at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.
